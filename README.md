# Duo Tracker

A World of Warcraft: Forever addon for two people levelling characters in pairs. It shows which character in each pair has fallen behind on level, RestedXP guide step and quests, and syncs both accounts over Battle.net whenever you are both online.

## Install or update

1. Download **Update Duo Tracker.bat** from this page (click the file, then the download button).
2. Double-click it. Windows may show "Windows protected your PC" the first time: click **More info**, then **Run anyway**.
3. Restart the game after the first install. After an update, type `/reload` in chat.

Keep the file on your desktop. Double-click it again whenever the addon says an update is available.

## In game

- `/duo` opens the window with every pair.
- `/duo help` lists the other commands.
